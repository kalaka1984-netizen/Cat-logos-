## 2025-08-06 - N+1 Query Resolution via SQL LEFT JOIN and TOTAL() in SQLite
**Learning:** Resolving N+1 query bottlenecks in loop-based GUI rendering (like `IC_Vista._refrescar_lista`) by pre-aggregating child record counts and price sums into a single query via a SQL `LEFT JOIN` and `GROUP BY` provides a ~37x rendering speedup (from ~0.058s to ~0.0016s for 200 records). Additionally, favoring the SQLite `TOTAL()` aggregate function over `SUM()` is critical because `TOTAL()` guarantees a `0.0` float value instead of `NULL` when no child rows match, preventing downstream Python `TypeError` exceptions.
**Action:** Always inspect loops in list-view rendering functions for repeated database lookups and replace them with pre-aggregated SQL JOIN queries utilizing safe aggregation functions like `TOTAL()`.
