## 2024-07-24 - N+1 Query on List Views & Exact JSON column matches
**Learning:** In Tkinter/CustomTkinter desktop applications backed by SQLite, list views that query children table details on a loop (N+1 query problem) are massive bottlenecks, reducing UI rendering speed by orders of magnitude. Replacing these loop queries with a SQL `LEFT JOIN` and SQL aggregation using `TOTAL()` enables immediate rendering. Additionally, query optimization of indexed columns (e.g. `nombre`) should always favor direct equality checks over expensive, serialized JSON column `LIKE` scans.
**Action:** Always inspect loops in list refreshes and replace N+1 queries with single SQL pre-aggregation queries. Bypas legacy generic `LIKE` lookup wrapper methods with direct select queries on indexed columns.
