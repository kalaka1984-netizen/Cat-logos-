## 2025-10-24 - Direct SELECT for Catalog Table Names
**Learning:** Functions like `cat_get_nombres_*` were previously delegating to `cat_buscar()`, which executes `SELECT id, nombre, datos_json, estatus, fecha_alta, fecha_mod ... WHERE nombre LIKE ? OR datos_json LIKE ?`. This unnecessarily fetched and transferred large `datos_json` blobs and performed expensive `LIKE` evaluations across all records. By using direct `SELECT nombre` queries with composite `(estatus, nombre)` indexes and a whitelist validation helper, list retrieval performance improved ~2.6x without JSON deserialization overhead.
**Action:** When extracting simple lists of key attributes from catalog tables, query specific columns with dedicated indexes rather than reusing generic search helpers that fetch whole rows or JSON blobs.
