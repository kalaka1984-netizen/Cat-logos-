## 2025-02-14 - N+1 Queries in GUI List Views
**Learning:** In Tkinter/CustomTkinter GUI list refreshes, fetching related child records (e.g. fractions for styles) within a loop introduces a severe N+1 query performance bottleneck. Since GUI event loop updates are blocked by these synchronous database lookups, it can lead to interface freezing. SQLite's aggregate function `TOTAL()` is superior to `SUM()` for left-joined records because it always returns a float and defaults to `0.0` when no child rows match, completely avoiding Python-side None-handling and type errors.
**Action:** When refreshing lists that display child totals/counts, design the select queries to pre-aggregate children using `LEFT JOIN`, `GROUP BY`, and `TOTAL()`, fetching all required data in a single SQL operation.
